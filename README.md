# 工业设备数据采集与监控上位机系统 (Tpt&ht_Module)

## 项目简介
本项目是基于 C# 和 WinForms 开发的工业监控上位机功能模块。系统支持通过串口连接扫码枪实现产品追溯，同时通过以太网 (Modbus TCP) 直连温湿度变送器，实现环境数据的实时采集、表盘展示与超限报警。
### 硬件清单
* **温湿度变送器**：仁科 RS-WS-ETH-6 系列（Modbus TCP 型，RJ45 网口输出）
* **网线**：标准 RJ45 以太网线
* **电源**：DC 7~30V 电源适配器（用于给温湿度传感器供电）
## 技术栈
* **开发语言**：C# (.NET 6 / WinForms)
* **UI 框架**：SunnyUI (现代化仪表盘组件)
* **通信协议**：Modbus TCP (基于 NModbus 库)、SerialPort (串口通信)
* **架构设计**：标准分层架构 (UI / Service / Entity / Tools)
* **数据存储**：本地 INI 配置文件持久化、TXT 运行日志记录

## 核心功能
1. **多协议通信**：实现 TCP 客户端网络连接与 Modbus 寄存器数据解析，以及串口数据的事件监听。
2. **实时监控大屏**：利用 SunnyUI 仪表盘实时渲染温湿度数值，秒级刷新。
3. **状态机报警**：实时比对采集数据与设定阈值，超限自动变红报警。
4. **异常处理与资源释放**：处理了网络断开、超时等异常情况，并规范释放底层 Socket 资源防止内存泄漏。
